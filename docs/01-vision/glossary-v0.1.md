# Glosario v0.1 StockFlow

| Término | Significado inicial |
|---|---|
| Producto | Artículo gestionado en el inventario, identificado por un código único. |
| Categoría | Agrupación lógica de productos para clasificación y reportes. |
| Ubicación | Espacio físico (almacén central o depósito) donde se guarda el stock. |
| Stock | Cantidad física disponible de un producto en una ubicación específica. |
| Movimiento | Transacción inmutable (entrada o salida) que altera el stock, con tipo, fecha y usuario. |
| Solicitud Interna | Petición formal de productos realizada por un solicitante interno. |
| Transferencia | Movimiento doble que genera una salida en un origen y una entrada en un destino. |
| Aprobación | Acción del supervisor que autoriza una solicitud en estado de borrador/enviada. |
| Alerta de Stock | Notificación generada cuando el stock de un producto cae por debajo del umbral mínimo en una ubicación. |
| Kardex | Registro histórico detallado de todos los movimientos de un producto. |
