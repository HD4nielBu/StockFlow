# Convenciones de Base de Datos — StockFlow v0.1 (Clase 05)

## Nombres
- Base: `stockflow` · Schema: `stockflow` · Rol de laboratorio: `stockflow_admin`
- Tablas: snake_case, singular (`movimiento_inventario`)
- Columnas: snake_case (`stock_minimo_default`)
- PK: `<tabla>_id`; constraint `pk_<tabla>`
- FK: columna `<tabla_referida>_id`; constraint `fk_<tabla>_<referida>`
- UNIQUE: `uq_<tabla>_<columna>`
- CHECK: `ck_<tabla>_<regla>`
- Índices: `idx_<tabla>_<columna>`
- Vistas: `vw_<nombre>` (`vw_kardex`)

## Tipos candidatos
- Identificador técnico: BIGINT GENERATED BY DEFAULT AS IDENTITY
- Texto corto: VARCHAR(n) con n justificado
- Texto amplio: TEXT
- Cantidades de inventario: NUMERIC(14,3) — admite fracciones de kilo o litro
- Mínimo por defecto del producto: INTEGER
- Importes: NUMERIC(12,2)
- Instante con hora: TIMESTAMPTZ (movimientos, solicitudes, auditoría)
- Booleanos: BOOLEAN
- Estados y tipos: VARCHAR(20/25) + CHECK
- Detalle flexible de auditoría: JSONB

## Regla de equipo
Toda excepción debe quedar justificada. Nunca FLOAT para cantidades ni importes, ni VARCHAR(255) por costumbre.
