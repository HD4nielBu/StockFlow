# Convenciones de Base de Datos StockFlow

## Nombres
- Tablas: snake_case, singular (ej. `producto`, `movimiento_inventario`).
- PK: `id` (cuando es inequívoco) o `tabla_id`.
- FK: `tabla_referenciada_id`.
- UQ: `uq_tabla_campo`.
- CK: `ck_tabla_campo`.

## Tipos candidatos
- Identificador técnico: `BIGINT GENERATED BY DEFAULT AS IDENTITY`.
- Textos cortos (códigos, nombres): `VARCHAR(50)` o `VARCHAR(100)`.
- Cantidades de stock: `INTEGER` (asumiendo unidades indivisibles) o `NUMERIC(10,2)` si son pesos/volúmenes. Para el MVP se usará `INTEGER`.
- Fechas/instantes audibles: `TIMESTAMPTZ`.
- Estados: `VARCHAR(30)` validado por CHECK o capa de aplicación.
