# Backlog v0.1 StockFlow

## Convención de prioridad
- P0: imprescindible para el flujo crítico del MVP.
- P1: importante para completar la operación.
- P2: complemento posterior.

### SF-001 Registrar producto y categoría
**Prioridad:** P0
Como administrador, quiero registrar productos y categorías para mantener el catálogo actualizado.

### SF-002 Registrar ubicaciones
**Prioridad:** P0
Como administrador, quiero crear ubicaciones para representar almacenes y depósitos físicos.

### SF-003 Crear solicitud interna
**Prioridad:** P0
Como solicitante interno, quiero crear una solicitud de productos para cubrir una necesidad operativa.

### SF-004 Aprobar solicitud
**Prioridad:** P0
Como supervisor, quiero aprobar o rechazar solicitudes para controlar el consumo interno.

### SF-005 Registrar movimiento (Atender solicitud)
**Prioridad:** P0
Como encargado de almacén, quiero registrar una salida de inventario para atender una solicitud aprobada actualizando el stock de forma transaccional.

### SF-006 Registrar transferencia
**Prioridad:** P1
Como encargado de almacén, quiero transferir stock entre ubicaciones asegurando salida en origen y entrada en destino.

### SF-007 Consultar Kardex
**Prioridad:** P1
Como encargado de almacén, quiero consultar el historial de movimientos (kardex) para auditar el flujo de un producto.

### SF-008 Visualizar alertas de stock
**Prioridad:** P1
Como supervisor, quiero ver un dashboard con alertas de stock mínimo para anticipar desabastecimientos.
