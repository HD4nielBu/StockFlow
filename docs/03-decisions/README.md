# Decisiones técnicas y de producto

Esta carpeta almacena decisiones arquitectónicas y de diseño del dominio (ADRs).

## Decisiones registradas:
1. **Identificadores (PKs):** Se usará `BIGINT GENERATED BY DEFAULT AS IDENTITY` para simplificar las relaciones relacionales, manteniendo los códigos de producto como `UNIQUE`.
2. **Stock Negativo:** El sistema bloqueará transacciones que resulten en stock negativo (implementado vía CHECK constraint o lógica de negocio validada antes de persistir).
